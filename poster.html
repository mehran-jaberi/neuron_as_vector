Methods · what the model is
01

The question

A scalar spiking neuron carries one number. Can making that number a vector buy computation — and does the gain survive a standard benchmark?

τ dV/dt = −V + I(t),   st = H(Vt − θ)

The scalar abstraction is the default in event-based networks. We keep the spike, the leak, the threshold and the count readout, and replace only the state: each of N = 100 neurons carries zi,t ∈ ℝD, with D = 1,000.

The spike remains one bit. The state that produces it is 1,000-dimensional.

02

The model

All coordinates of zi participate in the dynamics. The model is not a scalar neuron with a vector appended to its input.

03

Where the vector enters

  1. at = xtWin,   dini,t = gi ⊙ at
    Input projection: 1,400 × 1,000. The gate gi ∈ ℝD selects coordinates.
  2. mt = (ztWdown)Wup
    Intrinsic mixing, rank R = 64: 128,000 parameters, not N × D × D.
  3. ct = stWrec,   ht = (1/√N)(Σj sj,tzj,t)Wemit
    drect = ct ht
    Recurrent coupling and shared emission. A spike at neuron j gates the whole state vector zj.
  4. zt+1 = (1 − αi)zt + αi z̃t
    Leaky vector state. αi = σ(rawi) is learned; the reported initialisation is α ≈ 0.1.
  5. oi,t = ⟨zi,t, wout,i⟩ + θi − wadbi,t
    si,t = H(oi,t)
    The spike is a learned hyperplane through the whole state, not a scalar membrane potential.

The readout is unchanged: counts over time, then a linear classifier. Nothing about the spike is vector-valued — only the state behind it.

05

The full update

dt = gi ⊙ at + ctht + βi
mt = (ztWdown)Wup
m2t = (ztWdown2)Wup2
z̃t = tanh( mt + λ tanh( m2t + dt ) )
zt+1 = (1 − αi)zt + αiz̃t
oi,t = ⟨zi,t,wout,i⟩ + θi − wadbi,t
bi,t+1 = ρbi,t + si,t,   si,t = H(oi,t)

λ = 0.1 + 1.9 σ(λraw), initialised at 1.0. The reported model is the two-stage path with adaptation; the adLIF current block is present in the config but inert under two-stage mixing, so it is not shown.

Methods · protocol and controls
06

Training

L = CE + 10−4 · meani(ri − 10 Hz)2
SHD split8,156 train / 2,264 test
Input700 channels · 2 ms bins
SequenceT = 500 + 50-bin tail
OptimiserAdam · 10−3 · cosine
Batch / epochs96 / 30
Precisionfp16 state · fp32 masters
Thresholds10 Hz calibration

BPTT with 10 gradient-checkpoint chunks; gradients clipped at 1.0. Thresholds are calibrated for three fixed-point iterations and stay trainable.

07

Augmentation

Same-class blend

Two raw event lists of the same class are centre-of-mass aligned; each event is kept independently with p = 0.5, then merged and sorted. This is a mixup variant for event trains, applied before binning.

Event dropout

Each event is removed independently with p = 0.1. This is the only other augmentation active in the reported run. Both are training-only; validation and test events are byte-identical.

49.6% on FIT is the tell: the 1,000-neuron scalar does not fit the training split, so this is not a generalisation gap. In the same half-hour the vector gets 5 passes instead of 30 and still gains 33 points of TEST.

Not parameter-matched: 1.02M scalar vs 2.14M vector. The scalar spends 1M weights on a full recurrent matrix. The 30-epoch vector reaches 88.1% TEST / 99.8% FIT.

12

Probes

The code is in the trajectory, not the endpoint. The population mean uses only 7.49 effective dimensions out of 100,000.

13

A distributed code

Silencing one neuron costs 0.30 ± 0.63 pp on average. No single unit is necessary: the code is redundant and distributed, which is what a vector state predicts and a dedicated scalar detector does not.

14

Limitations

  • Single seed; no seed variance.
  • Blocks and augmentations selected on 5-epoch TEST.
  • No 30-epoch N = 100 all-off baseline.
  • VAL is speaker-overlapping; the held-out pilot overstates.
  • Scalar controls are untuned; the TEST set was read repeatedly.
  • The 5-epoch vector is the earlier 2.14M configuration, not the final 3.07M model.
Takeaway
Width of the state, not neuron count, is the variable that buys computation on SHD.

100 vector neurons reach 88.07%. A 1,000-neuron scalar does not even fit the training split.

15

What comes next

Design sketches, not measured results

Smaller footprint

Wemit ≈ D + U VT

A rank-16 emitter is about 33k parameters instead of 1M; factorising the input projection brings 1.4M down to about 38k.

Per-neuron embedding

gi = Wgei,   βi = Wβei,   wout,i = Woei

With ei ∈ ℝ8, the per-neuron heads cost about 8.8k for 1,000-D states, compared with 100k.

What would falsify it

If the SHD gain disappears at matched parameter budget, or under 30-epoch drop-one ablations, the claim is about parameters and training, not state width.
